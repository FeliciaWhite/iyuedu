# 朗读缓存音频下载功能开发文档

## 开发时间
2025年xx月xx日

## 功能概述
为阅读应用（Legado）添加朗读缓存音频下载功能，允许用户将 HttpReadAloudService 缓存的音频文件下载保存到本地。

## 需求背景
用户在阅读小说时，如果使用了在线朗读服务（如 HttpReadAloudService），每次朗读都会缓存音频文件。用户希望能够将这些缓存的音频文件下载保存到本地，方便离线收听。

## 技术方案

### 核心思路
复用 HttpReadAloudService 的缓存逻辑，按换行符分割章节内容获取朗读句子，查找对应的缓存音频文件，合并后保存到下载目录。

## 详细实现

### 1. HttpTtsAudioCache.kt

提供缓存文件的查询和验证功能：

```kotlin
package io.legado.app.service

import android.content.Context
import java.io.File

object HttpTtsAudioCache {
    
    /**
     * 获取章节缓存的所有音频文件
     * @param context 上下文
     * @param bookName 书籍名称（用于目录区分）
     * @param chapterIndex 章节索引
     * @return 缓存的音频文件列表，按文件名排序
     */
    fun getChapterCachedAudioFiles(context: Context, bookName: String, chapterIndex: Int): List<File>
    
    /**
     * 生成与朗读时一致的文件名
     * 使用文本的hashCode确保同一文本生成相同文件名
     */
    fun getFileName(context: Context, text: String, index: Int): String
    
    /**
     * 检查缓存文件是否存在
     */
    fun hasCacheFile(context: Context, bookName: String, chapterIndex: Int, text: String, index: Int): Boolean
}
```

### 2. AudioConcatUtil.kt

提供音频文件合并功能：

```kotlin
package io.legado.app.utils

import android.content.Context

import java.io.File

object AudioConcatUtil {
    
    /**
     * 合并多个音频文件
```

### 4. 下载功能实现

```kotlin
private fun downloadChapterAudio(chapter: ChapterBean) {
    // 1. 获取章节内容
    val content = readChapterContent(chapter.url)
    
    // 2. 按换行符分割（与正常朗读一致）
    val sentences = content.split("\n").filter { it.isNotBlank() }
    
    // 3. 查找缓存音频文件
    val cachedFiles = HttpTtsAudioCache.getChapterCachedAudioFiles(
        requireContext(),
        book.name,
        chapter.index
    )
    
    if (cachedFiles.isEmpty()) {
        showToast("请先播放该章节生成缓存")
        return
    }
    
    // 4. 合并音频并保存
    val outputFile = File(
        AudioConcatUtil.getDownloadFolder(requireContext(), book.name),
        "${chapter.index}_${chapter.title}.mp3"
    )
    
    val success = AudioConcatUtil.concatAudioFiles(cachedFiles, outputFile)
    
    if (success) {
        showToast("下载成功: ${outputFile.absolutePath}")
    } else {
        showToast("下载失败")
    }
}
```

## 使用说明

### 前置条件
1. 用户必须先使用朗读功能播放目标章节
2. 播放过程中应用会自动缓存音频文件到 `cache/tts/` 目录

### 使用步骤
1. 打开书籍详情页
2. 进入章节列表
3. 找到已缓存音频的章节
4. 点击右侧下载按钮
5. 等待合并完成，查看提示的保存路径

### 输出位置
```
/storage/emulated/0/Download/{小说名}/{序号}_{章节标题}.mp3
```

### 注意事项
- 同一章节需要先播放一次生成缓存，才能下载
- 下载按钮仅在存在缓存时显示
- 音频格式取决于缓存文件格式（支持 wav/mp3）

## 技术要点

### 1. 缓存目录结构
```
/data/data/{package}/cache/tts/{书籍名}_{章节索引}/
    ├── audio_{hash1}_0.wav
    ├── audio_{hash2}_1.wav
    └── ...
```

### 2. 文件名生成规则
使用文本内容的 `hashCode()` 生成文件名，确保：
- 同一文本内容生成相同的文件名
- 不同文本内容大概率生成不同文件名

### 3. 音频合并策略
直接拼接二进制文件内容，优点：
- 实现简单，无需编解码
- 处理速度快
- 保持原始音频质量

适用场景：
- 同格式音频文件（wav + wav 或 mp3 + mp3）
- 缓存文件来自同一朗读服务
