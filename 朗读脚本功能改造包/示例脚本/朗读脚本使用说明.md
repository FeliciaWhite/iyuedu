# 朗读脚本代码规范

## 一、基本概念

朗读脚本在系统准备好要合成音频的文本之后执行，脚本按列表顺序从上到下依次运行，前一个脚本的输出作为后一个脚本的输入。最终修改后的文本会交给系统TTS或转发器进行语音合成。

## 二、脚本环境

使用 **Rhino JS 引擎** 执行，支持 ECMAScript 5.1 语法。

## 三、内置变量

| 变量名 | 类型   | 说明                     |
| ------ | ------ | ------------------------ |
| `text` | String | 当前段落待朗读的原始文本 |

## 四、内置对象

### 1. `java` 扩展对象

通过 `java.xxx()` 调用，支持以下方法：

| 方法                            | 说明                                                         | 示例                                                         |
| ------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| `java.ajax(url)`                | 发送 HTTP GET 请求，返回响应文本                             | `java.ajax("https://api.example.com")`                       |
| `java.ajax(url, timeout)`       | 带超时时间的 GET 请求                                        | `java.ajax("https://api.example.com", 10000)`                |
| `java.readFile(path)`           | 读取应用缓存目录内的文件（字节数组）                         | `java.readFile("data.json")`                                 |
| `java.readTxtFile(path)`        | 读取应用缓存目录内的文本文件                                 | `java.readTxtFile("config.txt")`                             |
| `java.writeTxtFile(path, content)` | 写入文本到应用缓存目录                                       | `java.writeTxtFile("log.txt", text)`                         |
| `java.readExternalFile(path)`   | 读取外部存储文件（限制在 `/storage/emulated/0/Download/`）   | `java.readExternalFile("/storage/emulated/0/Download/test.txt")` |
| `java.writeExternalFile(path, content)` | 写入外部存储文件（限制在 Download 目录）                     | `java.writeExternalFile("/storage/emulated/0/Download/out.txt", text)` |
| `java.deleteExternalFile(path)` | 删除外部存储文件                                             | `java.deleteExternalFile("/storage/emulated/0/Download/old.txt")` |
| `java.deleteFile(path)`         | 删除应用缓存目录内的文件                                     | `java.deleteFile("temp.json")`                               |
| `java.encodeURI(str)`           | URL 编码                                                     | `java.encodeURI("中文")`                                     |
| `java.log(msg)`                 | 输出调试日志                                                 | `java.log("当前文本：" + text)`                              |
| `java.toast(msg)`               | 弹出 Toast 提示                                              | `java.toast("脚本执行成功")`                                 |
| `java.md5Encode(str)`           | MD5 加密                                                     | `java.md5Encode("hello")`                                    |
| `java.base64Encode(str)`        | Base64 编码                                                  | `java.base64Encode("hello")`                                 |
| `java.base64Decode(str)`        | Base64 解码                                                  | `java.base64Decode("aGVsbG8=")`                              |

> **路径说明**：`readFile/writeTxtFile/deleteFile` 使用的是应用私有缓存目录（`/android/data/{package}/cache/...`），无需权限。`readExternalFile/writeExternalFile/deleteExternalFile` 限制在 `Download` 目录下。

### 2. `cache` 缓存对象

用于在脚本之间或多次朗读之间保存临时数据。

| 方法                | 说明           | 示例                            |
| ------------------- | -------------- | ------------------------------- |
| `cache.get(key)`    | 读取缓存值     | `cache.get("myKey")`            |
| `cache.put(key, value)` | 写入缓存值     | `cache.put("myKey", "myValue")` |
| `cache.delete(key)` | 删除缓存值     | `cache.delete("myKey")`         |

### 3. `cookie` 对象

| 方法                 | 说明                  |
| -------------------- | --------------------- |
| `cookie.getCookie(url)` | 获取指定 URL 的 Cookie |

### 4. 直接调用 Java 类

Rhino 引擎允许直接访问 Java 类，例如：

```javascript
var response = org.jsoup.Jsoup.connect("https://api.example.com")
    .method(org.jsoup.Connection.Method.POST)
    .header("Content-Type", "application/json")
    .requestBody('{"key":"value"}')
    .timeout(10000)
    .ignoreContentType(true)
    .execute();
var body = response.body();
```

## 五、返回值

脚本最终需要返回一个字符串，作为修改后的朗读文本。有以下两种方式：

1. **直接写 `text` 变量作为最后一行**（推荐）
   ```javascript
   text = text.replace(/某个词/g, "替换词");
   text  // 最后一行表达式即为返回值
   ```

2. **显式返回**
   ```javascript
   text = text.replace(/某个词/g, "替换词");
   return text;
   ```

## 六、执行规则

1. **多个脚本**：按列表中从上到下顺序执行，上一个脚本的输出作为下一个脚本的输入
2. **禁用脚本**：未启用的脚本不会执行
3. **错误处理**：单个脚本执行出错时，会跳过该脚本并记录日志，不影响后续脚本和朗读流程
4. **空脚本**：代码为空的脚本会被跳过

## 七、注意事项

1. **变量名**：入口变量是 `text`，不是转发器里的 `speakText`
2. **性能**：脚本在每个段落合成前都会执行，避免执行耗时过长的网络请求，以免影响朗读流畅度
3. **网络请求**：如果需要频繁联网，建议将结果缓存到 `cache` 或本地文件中
4. **外部文件**：使用 `readExternalFile/writeExternalFile` 时，路径必须以 `/storage/emulated/0/Download/` 开头
5. **异常捕获**：建议对不确定的操作加 `try-catch`
   ```javascript
   try {
       var data = java.readExternalFile("/storage/emulated/0/Download/config.json");
   } catch (e) {
       java.log("读取失败：" + e);
   }
   ```

# 简单脚本示例

## 示例一：文本替换（基础）

将朗读文本中的"某某"替换为"某人"，适合简单替换需求。

```javascript
// 简单替换脚本
text = text.replace(/某某/g, "某人");
text = text.replace(/他妈的/g, "TMD");
text
```

## 示例二：联网获取替换规则

从远程接口获取替换词表，并应用到当前文本。

```javascript
// 联网替换脚本
var API_URL = "https://your-api.com/replace";

try {
    // 先尝试从缓存读取规则
    var rulesStr = cache.get("tts_replace_rules");
    var rules = null;
    
    if (!rulesStr) {
        // 缓存不存在，联网获取
        var resp = java.ajax(API_URL, 5000);
        rules = JSON.parse(resp);
        // 保存到缓存，避免每次请求
        cache.put("tts_replace_rules", resp);
    } else {
        rules = JSON.parse(rulesStr);
    }
    
    // 应用替换规则
    if (rules && Array.isArray(rules)) {
        for (var i = 0; i < rules.length; i++) {
            var rule = rules[i];
            var regex = new RegExp(rule.from, "g");
            text = text.replace(regex, rule.to);
        }
    }
} catch (e) {
    java.log("联网替换失败：" + e);
}

text
```

## 示例三：读取本地配置文件进行替换

将替换规则保存在手机 Download 目录下的 JSON 文件中。

```javascript
// 本地配置替换脚本
var CONFIG_PATH = "/storage/emulated/0/Download/tts_replace.json";

try {
    var configStr = java.readExternalFile(CONFIG_PATH);
    if (configStr && configStr !== "") {
        var config = JSON.parse(configStr);
        if (config.rules && Array.isArray(config.rules)) {
            for (var i = 0; i < config.rules.length; i++) {
                var r = config.rules[i];
                text = text.replace(new RegExp(r.from, "g"), r.to);
            }
        }
    }
} catch (e) {
    java.log("读取本地配置失败：" + e);
}

text
```

## 示例四：记录朗读日志

将每次朗读的文本记录到本地文件中，方便调试。

```javascript
// 朗读日志记录脚本
try {
    var logEntry = new Date().toLocaleString() + " | " + text + "\n";
    var existing = java.readExternalFile("/storage/emulated/0/Download/tts_log.txt") || "";
    java.writeExternalFile("/storage/emulated/0/Download/tts_log.txt", existing + logEntry);
} catch (e) {
    // 记录失败不影响朗读
}

text
```

## 示例五：Jsoup 直接发 POST 请求

适合需要自定义请求头的场景。

```javascript
// API 标注脚本示例
try {
    var apiCfg = {
        url: "https://api.example.com/chat/completions",
        key: "your-api-key"
    };
    var requestBody = JSON.stringify({
        "model": "gpt-3.5-turbo",
        "messages": [{"role": "user", "content": "请总结这段文字：" + text}]
    });
    
    var response = org.jsoup.Jsoup.connect(apiCfg.url)
        .method(org.jsoup.Connection.Method.POST)
        .header("Authorization", "Bearer " + apiCfg.key)
        .header("Content-Type", "application/json")
        .requestBody(requestBody)
        .timeout(8000)
        .ignoreContentType(true)
        .execute();
    
    if (response.statusCode() == 200) {
        var resJson = JSON.parse(response.body());
        var result = resJson.choices[0].message.content.trim();
        // 可以在这里使用 API 返回的结果修改 text
        // text = result;
        java.log("API 返回：" + result);
    }
} catch (e) {
    java.log("API 请求失败：" + e);
}

text
```
